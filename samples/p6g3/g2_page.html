P6g gate G2: the default of kern.kwq.bulk.place

Both schemes of gate G1 are in the kernel behind one knob and were measured on lab (one package, SMT) and a07 (128 cores, one package) against today's code. P8 holds or beats today on kwq-geli on both machines. For a closed-loop queue on one CPU it needed the chain: an idle thief that retries the victim of its last batch before it sleeps. With it, P8 meets all five kernel criteria on both machines. Gossip falls behind on a07 and on that queue. The decision is crest's.

Decided by crest (SPEC-p6g.md D12-D15)

  • D12: option A. P8 is the default on a machine of one package and today's code on more; place=0 stays for one round of A/B. smp_topo() has no package level, so the kernel takes one NUMA domain for one package; a two-socket machine with interleaved memory shows one domain.
  • D13: shard.directed=2 (the chain) with shard.directed_us=10.
  • D14: spill_idle and helper_donor removed.
  • D15: gossip stays in the kernel for the hybrid H4; a07's ssd randread is taken as level with today.

In the code since commit 77e80dc. The options and questions below are the report as it was put to the decision. The code at these defaults was measured again at b70e3db: the criteria tab's rows "P8, G2 defaults" and round 3 of the interleaved A/B on the kwq-geli tab (thirty randread runs of each).

A. P8 with the chain the default on machines of one package (recommended)

kern.kwq.bulk.place=2 with shard.directed=2 and shard.directed_us=10 where smp_topo() shows one package; spill_idle and helper_donor stay off. Today's code (place=0) stays for one round of A/B (decision D3). Machines of two or more packages keep place=0 until one is measured: the simulator's two-socket model shows P8 collapsing near saturation, and no machine here has two sockets.

B. P8 with the chain the default everywhere

The same without the package rule: simpler, and it trusts that the two-socket model is wrong where it was never checked.

C. Today's code stays the default

P8 and gossip stay opt-in until a two-socket machine is measured and a07's ssd randread case is resolved with many more runs.

Decisions for crest

  1. The default of place: A, B or C.
  2. P8's shard.directed: 2 with directed_us=10 (recommended: the mailbox and the chain only for lists whose items cost at least that much, which the 64 KiB crypto items do and the 4 KiB GELI reads do not); 2 with directed_us=0 (every list); or 1 (the mailbox alone, which left a07's one queue far behind today). The gate's value is a judgment between the two item classes measured, not a derived bound.
  3. The knobs nothing needs any more, spill_idle and helper_donor (and directed_us if 2 without the gate is chosen): take them out of the code, or keep them off as experiments.
  4. Gossip (place=1): keep it in the kernel as the hybrid study's base for machines of several packages (H4), or take it out. It fails K2 and K4 on lab and K1 to K4 on a07.
  5. The hybrid: H1 (gossip with lazy idle lines) is dropped by its numbers; H4 (P8 within a package, gossip's hand-off across packages) needs a two-socket machine. Pursue H4, or close the study?
  6. a07's ssd randread: every configuration's runs fall in a fast or a slow mode, and P8 without the chain ranged from below today to above it across four rounds, so six runs cannot resolve ten per cent. Accept P8 as level with today there, or measure with many more runs (about forty minutes for thirty runs per setting)?

What changed since the first measurements

  • The chain (777b372): a lone item behind running work never makes its CPU a donor, so a P8 thief slept after each batch and every item of a shallow list waited for a wake. shard.directed=2 retries the last victim; the first miss forgets it.
  • The gate (3c5c2cd): shard.directed_us limits the mailbox and the chain to costly items. Neither the K4 rounds nor randread need it; it confines the new behaviour to where it was measured.
  • Two fixes found on the way: the steal wake no longer reads the queue after the enqueue drops the list lock (b40b3a6), and the pass cost average leaves out ticker glitches, which on a07 had driven some lists' cost past 2^63 ns (946967d).
  • K2 on lab sat at the edge in the chain's own round; the interleaved A/B on the kwq-geli tab settles it: the chain leaves the bulk writes where P8 had them, a little below today's.
